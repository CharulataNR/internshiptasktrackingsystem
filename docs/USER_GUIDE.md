# User Guide

(The same guide is available inside the application under **User Guide**.)

**Roles.** Administrator: full access. Team Lead: own team only - create/edit tasks, update status, assess, download reports.

**Add interns.** Intern Master > Add intern > fill name, DIT ID (unique), email, 10-digit phone, college, role, joining date (team optional) > Add intern. Search by name/DIT ID/email; filter by college and team.

**Create teams.** Team Management > Create team > name, description, leader. On the team page use *Manage members* to add unassigned interns, remove members or change the leader. To move an intern to another team edit the intern.

**Assign tasks.** Task Tracker > New task > title, description, intern (DIT ID appears), assigned date, due date > Create task. Due date cannot be before the assigned date.

**Update task status.** Use the status dropdown on the task row (saves instantly) or open the task. Flow: Not Started > In Progress > Submitted > Under Review > Completed / Rejected. Submission date fills automatically.

**Track overdue tasks.** Not Started / In Progress tasks past their due date show as Overdue automatically. See the dashboard Overdue card and table, or filter Task Tracker by status Overdue.

**Assess work.** Assessment Management > Assess > choose status, score 0-100, remarks. Approved completes the task, Rejected returns it for rework.

**Generate reports / export Excel.** Reports page: eight Excel downloads and a printable Team Lead report per team. Task Tracker: apply filters then *Export filtered Excel*.

**Settings.** Change your password; admins also create team-lead accounts, reset passwords, disable users and view the activity log.
